## 1. 产品目标与当前差距

目标：用户给出剧本或小说，Agent 自动产出可观看的 AI 漫剧/短剧（分集、分场、分镜、角色一致、配音/字幕/音乐、成片导出）。

| 能力 | 现状 | 差距 |
|---|---|---|
| 一句话 → 多镜头 → 成片 | 已可用（Wan/i2v/flf2v/Kling/fal 受控） | 只适合短片/演示，缺长文本改编 |
| 长文本 → 分集/分场/分镜 | 只有单次 storyboard 工具 | 缺章节切分、场景节拍、台词/角色结构化 |
| 角色/风格一致性 | 素材库 + i2v/flf2v 参考图 | 缺角色圣经、风格圣经、跨镜头一致性校验 |
| 成片后期 | 仅拼接/转码 | 缺转场、字幕、配音、配乐、响度、片头片尾 |
| 多集/批量 | 单项目、单成片 | 缺 Episode/Season 模型、队列、失败重试 |
| 工作台 | 分镜面板 + 成片播放 | 缺时间线编辑、字幕/音轨、逐镜头裁剪 |
| 供应商 | Wan 真实；Kling/fal 未做真实样本 | 缺真实账号验证、账单、能力路由 |
| 发布 | 本地 wheel | 缺版本发布/PyPI/安装器 |

## 3. M5：剧本/小说 → 分集分场分镜（P0）

### 3.1 范围

- 输入：纯文本剧本/小说章节（先 txt/markdown；PDF/网页导入后续）。
- 输出：`Episode → Scene → Shot` 结构化数据；每个 Shot 含台词、角色、时长、景别、运镜、模式（t2v/i2v/flf2v）、参考素材。
- 角色圣经：姓名、外观、服装、声音、关系、参考图素材；风格圣经：题材、色调、镜头语言、字幕样式、目标时长。
- 改编规则：章节/场景切分、节拍、镜头数上限、每集 60–180 秒（先以 60–90 秒验收）。
- 显式确认 + 预算：先出计划与逐镜头估算，用户确认后登记生成；不自动提交付费任务。

### 3.2 工作包

| 包 | 交付 | 验收 |
|---|---|---|
| E0 契约冻结 | Episode/Scene/Character/Style 数据对象；schema v6 迁移；文本切分与镜头预算；错误码 | 旧 v1–v5 数据可读；迁移有字节备份；无模型调用。**已交付**：[契约](./M5_CONTRACTS.md)、[E0 验收](./M5_E0_ACCEPTANCE.md) |
| E1 文本改编 | 章节/场景切分、对白抽取、镜头草案、角色识别 | 固定 3 篇样例文稿，输出结构完整；不丢对白；可复现。**已交付**：[E1 验收](./M5_E1_ACCEPTANCE.md) |
| E2 角色/风格一致性 | 角色圣经、参考图导入、镜头引用角色 ID、风格提示模板 | 同一角色跨镜头引用同一组素材；缺素材拒绝；人工一致性评分记录。**已交付**：[E2 验收](./M5_E2_ACCEPTANCE.md) |
| E3 生成与重做 | 批量登记、逐镜头重做、预算、集合等待、失败隔离 | 60–90 秒样例全链路；重做只影响目标镜头；submit 与预算一致。**已交付**：[E3 验收](./M5_E3_ACCEPTANCE.md) |
| E4 验收与文档 | 离线端到端套件、真实小样本、CLI/Web 流程、验收文档 | 3 篇样例中至少 1 篇真实生成并成片；失败保留；CI 通过。**已交付**：[E4 验收](./M5_E4_ACCEPTANCE.md)（离线 5/5、安装态 PASS、浏览器 5 阶段、`fridge-notes` 真实 18 镜头 / 7 条逐场成片） |

### 3.3 验收样例

- 1000–2000 字中文故事 → 1 集（60–90 秒）→ 10–20 个镜头 → 全部交付 → 成片可播放。
- 角色 A 在至少 3 个镜头出现，引用同一角色素材；人工检查外观一致性。
- 预算：逐镜头估算 + 每集上限；超限整批拒绝；不自动重提。
- 真实样本只做一个最小集；Kling/fal 仍可只用受控 HTTP。

## 4. M6：成片后期（P0）

### 4.1 范围

- 转场：cut（默认）、fade、crossfade；转场时长与镜头时间线在成片版本中冻结。
- 字幕：从台词生成 SRT/ASS；软字幕/烧录两种；时间轴按镜头对齐；支持手动修正。
- 配音：TTS（中文、情绪/语速）、角色音色映射；先接一个 TTS 供应商，保留替换接口。
- 音乐/音效：BGM、SFX、ducking；只使用可商用/ royalty-free 素材；记录来源。
- 响度：统一到 -16 LUFS（true peak -1 dBTP）左右；输出前测量。
- 片头/片尾/标题卡：文字渲染；不做复杂动效。
- 导出：16:9 720P/1080P H.264 + AAC；码率/帧率可配置；保留 copy 优先、必要时转码。

### 4.2 工作包

| 包 | 交付 | 验收 |
|---|---|---|
| E0 契约冻结 | 字幕/音轨/转场/导出 profile；成片版本 v6；TTS/音乐来源策略 | 旧成片可读；无供应商调用。**已交付**：[契约](./M6_CONTRACTS.md)、[E0 验收](./M6_E0_ACCEPTANCE.md)（schema 7 方向、7 个决策点、18 个错误码、126 个契约基线哈希、FFmpeg 能力探针） |
| E1 字幕 | 台词 → SRT/ASS；烧录与软字幕；时间轴对齐 | 60 秒样例字幕不漂移；中文字体可用；可手动修正。**已交付**：[E1 验收](./M6_E1_ACCEPTANCE.md) |
| E2 音频 | TTS、BGM/SFX、ducking、响度 | 人声清晰；无削波；响度测量通过；来源可追溯。**已交付**：[E2 验收](./M6_E2_ACCEPTANCE.md) |
| E3 转场/片头片尾/导出 | xfade 等；标题卡；720P/1080P 导出 | 转场无黑帧/音画不同步；导出可播放；时长正确。**已交付**：[E3 验收](./M6_E3_ACCEPTANCE.md) |
| E4 验收 | 60–90 秒成片；浏览器播放；音频/字幕检查；文档 | 一条完整短剧成片；失败保留；CI 通过。**已交付**：[E4 验收](./M6_E4_ACCEPTANCE.md) |

### 4.3 决策点

1. TTS 供应商与音色（中文情绪、是否需要声音克隆/授权）。
2. 音乐/音效来源与商用许可。
3. 字幕默认烧录还是软字幕；字体与样式。
4. 是否引入 1080P 导出（转码成本/时间）。
5. 供应商水印：当前 Wan 固定 `watermark=true`，成片带“AI 生成”水印；是否申请关闭/接受。

## 5. M7：多集与工作台（P1）

### 5.1 范围

- **Season/多集**：一个项目可有多个季，季只保存有序的 Episode 成员与标题；每集仍独立拥有场记、分镜、预算与成片，角色/风格继续由项目级圣经共享。一集至多属于一个季的当前版本。
- **批量队列**：一次 `season_generate` 覆盖 1–3 集，逐集原子登记；单集失败隔离，显式 `resumeBatchId` 恢复，绝不因恢复而重复提交；批量上限 60 Job / 180.00 CNY，逐集 20 Job / 60.00 CNY 不变。
- **时间线工作台（Web 优先）**：每集一条只增不改的时间线；重排/裁剪镜头、设置转场点、选择字幕轨/音轨/标题卡；客户端顺序预览；导出走本地 `ffmpeg-render-timeline-v1`，生成新的成片版本。BGM/SFX 由客户端受控上传（许可与来源必填），不作为模型工具暴露本地路径。
- **逐镜头重做与局部重拼**：继续复用 `shot_redo`、M4 归一化与 M6 渲染；时间线编辑只追加新版本，旧成片与旧时间线版本保留。
- **不做**：9:16 竖屏、多轨混音工作站、关键帧/变速/特效、自动后台批处理守护进程、跨项目季、跨集“超级成片”。

### 5.3 决策点（2026-10-23 已冻结）

1. **Season 形状**：季只保存成员顺序与标题，不复制角色/风格，不拥有成片或预算；一集至多属于一个季的当前版本。
2. **批量语义**：批次是显式确认的批量登记，不是后台守护进程；逐集原子、单集失败隔离、恢复必须显式；不自动重提。
3. **批量上限**：1–3 集、60 Job、180.00 CNY；逐集 20 Job / 60.00 CNY 不变；不换汇。
4. **时间线**：每集一条只增不改的时间线；一条版本冻结有序镜头（含裁剪）、转场点、字幕轨、音轨、标题卡；渲染只读确定版本。
5. **渲染**：复用 M4 归一化 + M6 本地管线，新增 `ffmpeg-render-timeline-v1`；30 fps 网格、±1 帧容差、同指纹幂等；不回写旧字面量。
6. **预览**：Web 客户端顺序播放 + 裁剪偏移，仅用于编辑；服务端不生成预览成片，导出才是交付物。
7. **并发**：每季至多一个 `running` 批次；供应商提交仍由既有 Job Worker 串行约束；批次等待按集分段（每段 ≤20 个 Job）。
8. **素材导入**：BGM/SFX 由客户端受控上传（Web/CLI），必须 `license`/`sourceUrl`；不是模型工具，不引入第三方音乐 API。
9. **付费样本**：E0–E3 submit=0、模型调用=0、TTS 请求=0；E4 只复用已有本地媒体，新增样本须单独授权。

### 5.4 验收样例

- 3 集（每集 10–20 镜头、60–90 秒）加入同一季；一次批量登记，其中 1 集因未绑定场记/预算不足失败，其余 2 集完成登记并各自交付。
- 对失败集修复后显式恢复：只处理未成功集，已验证的镜头 Job 复用，不产生重复提交；批次状态从 `partial` 变为 `succeeded`。
- 让其中一集的一个镜头交付失败：其他集与其余镜头继续交付，`season_read` 显示该集 `failedShots=1`；用 `shot_redo` 修复该镜头后该集可继续，批次登记记录不被交付结果改写。
- 对一集建立时间线：重排 2 个镜头、裁剪 1 个镜头、设置 1 个转场与 2 张标题卡，导出 v1；再调整顺序/裁剪导出 v2；两条成片版本与两条时间线版本均保留，v1 不被改写。
- 浏览器：季面板显示 3 集与逐集状态；时间线面板可拖动/裁剪/预览/导出；成片可播放、字幕可开关；页面错误 0。

### 5.5 边界

## 7. 跨切面
