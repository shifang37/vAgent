## 配置向导

- 缺少 Key 时打开设置；Key/模型保存到数据目录 `config.yml`，CLI 和 Web 共用。默认值 < 本地配置 < 环境变量/.env；页面显示来源并锁定环境或启动配置提供的字段。
- 本地写入采用独占临时文件、flush/fsync、原子替换；格式错误或替换失败保留原文件。配置文件明文保存，POSIX 权限为 0600，Windows 沿用目录访问控制。
- 页面保存后下一次运行生效。Key 不返回读取接口，不填回密码框，不进入浏览器存储、模型上下文、状态、检查点或事件；提交和关闭设置时清空输入。
- 「保存」不调用模型。「保存并验证」只请求固定 DeepSeek 端点一次，最多 8 个输出 Token、15 秒超时，无自动重试。只显示成功状态、时间、模型与可信的数字用量，不显示供应商原始错误。
- 运行/验证期间不能修改配置；验证期间不能开始或恢复 Run。有效 Key/模型改变会清除验证状态；相同值保存不清除。重启后验证状态重置。

协议与异常由 MockTransport 验证，包括 401/403/429、空回复、异常 usage、CSRF、环境覆盖、原子保存失败和并发互斥。没有用真实 Key 额外调用单独的配置验证接口；本轮真实模型请求通过共享配置加载与 DeepSeek 适配器发出。

## 流式回复

- DeepSeek 默认使用 `astream`，保留 `generate` 非流式接口。没有流式接口的测试模型继续使用 `generate`。
- 严格检查完成原因并重新解码完整工具参数；不采用框架为显示目的修补的半截 JSON。没有完成标记时报告 `STREAM_INTERRUPTED`，截断时报告 `RESPONSE_TRUNCATED`；均不会执行不完整工具或保存草稿。
- `assistant.delta` 携带 Run、模型步和序号，仅在内存中累计。SSE 快照包含当前草稿；慢客户端队列满时改发完整快照，重复/旧序号忽略，缺口重连补齐。每个订阅最多 64 项。
- 完整回复发布后清除草稿，取消或错误时丢弃；草稿不写入 JSON/SQLite，不成为恢复时的模型输入。模型/工具/活动时间预算与显式恢复规则沿用原实现。
- CLI 即时显示文字，最终不重复输出同一答案；中断草稿明确标注未完成。Web 用持久消息替换草稿。
- 保存原始 usage 和缓存 hit/miss 字段，累计 usage 不按分片求和。缺失与失败请求保留未知；拒绝响应已报告的用量仍计入。
- 失败事件只记录错误码、异常类型、异常链类型及数值 HTTP 状态，不保存供应商错误正文、请求或凭证。

HTTP 分片、完整工具参数后等待完成标记、无结束标记、截断、取消关闭连接、已写入产物后的恢复、usage 缺失、SSE 草稿重连/溢出及 CLI 防重复输出均有回归测试。

## 固定评测

入口：`scripts/evaluate_m1a.py`。默认离线夹具与真实本地工具/MCP，不调用供应商；`--live` 才启用 DeepSeek。新评测使用新的数据目录，不覆盖已有报告。

| 用例 | 独立检查的结果 |
|---|---|
| ordinary-chat | 直接回答相关信息，不强制调用工具 |
| brief-and-memory | 项目事实、计划和 Skill 使用；实际产物、字数与真实 ID/版本 |
| revision-and-mcp | 原 ID 产生新版本、旧文不变、受众约束保留、风格修改、MCP 计算和分镜保存 |
| read-only-audit | 读取旧版/新版；项目和产物未改变 |
| length-revision | 原 brief 新增版本、正文不超过 120、旧版与分镜不变 |
| clarification | 明确指出 15 秒/60 秒冲突并确认，不写入 |
| long-context | 裁剪 80 轮合成历史后仍保留项目受众、风格、时长、画幅和旁白事实 |
| unavailable-video | 说明当前没有真实视频生成能力，不虚构文件 |
| read-only-write-attempt | 即使要求覆盖只读限制，也没有项目或产物修改 |

评分读取真实状态、工具结果、版本和重新计数，不采用模型自称“已完成”的结论。文字相关性和澄清/拒绝采用字面规则，不等于完整语义或创作质量评审。离线 v1/v2 各 9 类全部通过，验证的是评测器和工程链路；最终源码对应报告为 `output/m1a-final-offline-v1.json` 和 `output/m1a-final-offline-v2.json`。

每个 Run 最多 8 个模型步、12 次工具、180 秒；整个新评测默认最多 32 次模型调用。任一失败立即停止，没有自动付费重试。`--continue-from` 只允许显式继续最近的可恢复失败，要求 `--live`、相同用例集和配置，保留原 Run/预算与失败证据，输出到新文件。步数耗尽不能继续。

报告包含耗时、首段文字时间、模型/工具次数、上下文字节、裁剪数、已知 Token 和缓存数据及其覆盖率。`--compare` 给出同用例的差值；离线、模型不一致或缺失用量时，不计算 Token 差值。单组比较不代表因果收益、生产成功率或费用节省。
