# SQLite 持久恢复验收

日期：2026-09-29。范围：本地 CLI 的持久图检查点与显式恢复；不代表整个 M1-A 或真实模型任务验收。

## 实现

- 使用 `AsyncSqliteSaver`，存储路径为 `VAGENT_HOME/checkpoints.sqlite`；未配置数据目录时使用 `~/.vagent/`。不需要独立数据库服务。
- `thread_id = runId`，以 `durability="sync"` 执行 LangGraph。只有显式 `resume` 会继续原图；同 request ID 的 `run` 仍只返回已有记录。
- `state.json` 的 RunJournal 在模型调用前记录尝试次数，工具执行前记录唯一调用额度。检查点回退不会使预算回退；工具结果与业务修改由现有操作日志一起提交。
- 操作键为 `runId:modelStep:toolCallId`。批次内部分工具已经完成时，恢复复用原结果并执行剩余工具，不重复增加额度或产物版本。
- 正常结束先完成图检查点，再提交成功会话。恢复发现图已经结束时，只补交会话快照。
- 同一数据目录仍只允许一个写进程、一个活动 Run。SQLite 不替代实例锁和操作幂等。

## 验证证据

执行 `python -m pytest -q`：59 passed、1 skipped（Windows 账户无符号链接权限）。新增恢复测试位于 `tests/test_resume.py`。

Ruff lint/format、`git diff --check`、sdist/wheel 构建通过。另在新建独立虚拟环境中安装 wheel，并在仓库之外通过 CLI 恢复已保存产物后取消的离线 Run：模型步数累计为 4，最终仍只有一个产物；`pip check` 通过。这些打包和恢复检查仅在本机 Windows / Python 3.12 执行，未宣称远端 CI 已通过。

| 场景 | 验证结果 |
|---|---|
| 保存产物后模型请求失败，关闭 Store 再打开 | 同一 Run 从原工具结果继续，保留 request ID 与产物 |
| 用户取消工具执行，随后显式 resume | 停止快照中的调用/结果配对完整；恢复后执行未完成工具 |
| 外部 asyncio 取消正在执行的模型请求 | 状态为 cancelled；恢复后尝试次数继续累计，已取得的 usage 保留 |
| 两个工具中第一个提交后，子进程 `os._exit(73)` | 重启只实际执行第二个工具，总计两个产物、各一个版本、两次工具额度 |
| 工具全部提交后，下一次模型请求中子进程强退 | 恢复不再保存产物；丢失响应的模型尝试仍计步，预留时间只扣一次 |
| 图终态已持久化、成功会话尚未提交 | 恢复时不调用模型，使用检查点中的最终回复补交会话 |
| 恢复时传入更高的 Runner 限额 | 沿用原 Run 限额，达到步数或时间限制后不再调用模型 |
| 同一会话提交了新请求 | 拒绝恢复旧 Run，保留新会话历史 |
| 同时发起两次 resume | 仅一个执行，另一个收到 RUN_BUSY |
| Skill/上下文等配置发生变化 | 拒绝恢复，提示恢复原配置 |
| 旧版 Run、检查点缺失或数据库损坏 | 不从头执行；损坏文件保留 |
| 离线 Run 从仓库外通过 CLI resume | 无 Key 完成恢复；仍使用原 Run ID |
| 已完成 Run 再次 resume，或重复原 request ID | 直接返回原结果，不增加模型调用 |

## 使用与限制

```text
vagent inspect --session coffee
vagent resume RUN_ID
```

CLI 会展示 Run ID 和可恢复提示。鉴权、限流、网络错误、单次模型请求超时及用户取消可在剩余预算内显式恢复。步数、工具次数、总时间耗尽，以及非法调用协议等错误不能通过 resume 绕过。

强退后的 `instance.lock` 仍需确认原进程已经退出后手动移除，程序不抢锁。测试只在已确认子进程退出后清除其测试目录锁文件。旧版成功会话仍可继续对话，但旧版未完成 Run 无法追溯产生检查点。

活动时间跨恢复累计，离线时间不计入。正在执行的模型请求会预留最多 60 秒（受剩余总时间限制）；进程强退时按预留上限保守扣除一次。重新请求模型可能重复产生供应商费用，未返回 usage 的请求无法准确计入 Token 总量。

同步本地工具执行仍不可抢占。JSON 业务状态与 SQLite 图状态是两份存储，依靠操作日志处理提交间隙，不能只恢复其中一个文件来承诺一致恢复。应在进程退出后备份整个数据目录。

测试使用离线模型、模拟 HTTP 和真实本地子进程；未调用真实 DeepSeek，未引入 Redis、回答缓存、自动摘要、视频任务或 Web。
